# AI Factory · 机房与集群建设

独立妙搭交互原型，应用 `app_17g9gf82h7h`。复用既有三个原型的 AI Factory 视觉样式，不修改既有应用或生产代码仓库。

机房为一级实体，独立展示负责人、区域、排期、三阶段 SOP、耗时与阻塞；展开后为该机房的集群明细。过去 / 现在 / 未来可切换，保留全阶段时间线。机房交付验收与集群交付分别记录。

范围：内场新建，覆盖中国与非中。FY26 rev1482 将部分 on 火山项目归为内场；按项目归属而非云基础设施名称过滤。示例不是实时资产清单。

数据边界：名称/标识参考 2026-10-12 原型资料快照（派生输出 / T4）；状态、日期、耗时、SLA、阻塞及负责人分配为示例。未确认名称/VDC/集群组/数量/负责人保持待确认。集群六阶段及其说明、子项逐项读取自《集群管理设计》rev246（2026-10-18 外部文档 / T6）；机房三阶段来自本次用户要求。原型不定义长期团队口径。

静态入口 `index.html`，不依赖构建。`data.js` 保存示例数据；`sop-data.js` 保存 SOP 转录；`cluster-model.js` 定义纯聚合与时间线逻辑；`hierarchy-view.js` 渲染父子层级；`detail-view.js` 渲染机房 / 集群抽屉；`app.js` 绑定交互；本页样式写于 `hierarchy.css`。

参考来源、资料版本、新鲜度、置信度及缺口可在页面“参考与口径”查看。该原型不连接生产系统，不执行机器、集群、工单或通知变更。
